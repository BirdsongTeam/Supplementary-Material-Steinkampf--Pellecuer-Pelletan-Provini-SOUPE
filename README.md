**DATA \& FILE OVERVIEW**

File list:

SM1: codes and documentation

* SM1a: SOUPE package. Please don't skip the **"SOUPE Tutorial.md"** file, that contains the complete tutorial to install and use the package. The .zip file is the package to be installed, the .tar.gz file is the source code. Please have a look at **"SOUPE Decision Tree.png"** file for a detailed step by step through the different options of the functions.
* SM1b: code for the case studies
* SM1c: detailed explanation of the case studies
* SM1d: supplementary figures



SM2: files for the first case study: evaluation of a sample used in a study on birds’ locomotion abilities (Provini \& Höfling, 2020)

* SM2a: tested sample
* SM2b: traits table
* SM2c: phylogenetic tree



SM3: files for second case study: creation of a sample for the digitization campaign of birds’ fluid collection in natural history collections (e\_COL+ project).

* SM3a: available taxa: taxa in fluid collection
* SM3b: key species list with already scanned and priority species
* SM3c: traits table
* SM3d: phylogenetic tree

**METHODOLOGICAL INFORMATION**

Description of methods used for collection/generation of data:

SM1: the codes, figures, and explanations were created by ourselves

SM2: data were taken from Provini \& Höfling (2020) and McTavish et al. (2024), and modified after Lepage et al. (2014)

SM3: data were taken from the inventory of MNHN Birds' fluid collections and McTavish et al. (2024), and modified after Lepage et al. (2014)
